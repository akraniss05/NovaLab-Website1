# NovaLab Launcher v0.7.0 – Early Access

## Enthalten
- Admin Publishing Studio: Datenbankspiele anzeigen, bearbeiten, archivieren, wiederherstellen, nach archivierter Bestätigung endgültig löschen.
- Github-Katalogspiele können aus dem öffentlichen Katalog ausgeblendet und wiederhergestellt werden; die zugrundeliegenden Repo-Dateien werden dabei nicht gelöscht.
- Mehrfachauswahl für Archivierung und Wiederherstellung (max. 30 Einträge pro Vorgang).
- Löschdialog mit exakter Eingabe des Spieltitels und serverseitiger Rollenkontrolle.
- Sichere Dateibereinigung bei Datenbankspielen nach Referenzprüfung; lokale Installationen der Benutzer bleiben erhalten.
- NovaLab Code 1.0.1 ist im offiziellen GitHub-Katalog als echte Desktop-Anwendung mit dem geprüften ZIP-Release und SHA-256 registriert.
- NovaLab Code: eigene Cover- und Banner-Assets; keine erfundenen Gameplay-Screenshots.

## Technische Fakten
- Die Coding-App ist die bestehende NovaLab-Code-Lernplattform aus dem Originalrepository; Electron liefert das vorhandene Frontend gebündelt aus.
- Download-URL: https://github.com/akraniss05/NovaLab-Code/releases/download/code-v1.0.1/NovaLab-Code-win-x64-v1.0.1.zip
- GitHub-Asset-SHA256: 5a747472ac4e328f4277e4fab4b6758b278e1c092169c6c48d5b6d4f5292f4f3
- Downloadgröße: 164779735 Byte.
- Update-Mechanismus: neue verifizierte ZIP-Veröffentlichung kann dieselbe Spiel-ID mit höherer Versionsnummer verwenden; die vorhandene Installation wird während eines Updates gesichert.
- Die vorhandene Supabase-Studio-API erzwingt serverseitige Admin-Authentifizierung bei Lösch-, Archivierungs- und Massenaktionen.

## Getestet / offen
- GitHub Actions: Node-Syntaxcheck, vorhandene Unit-Tests für Download-/Update-Manager, Live-API-Tests für öffentliche Daten und Ablehnung anonymer Admin-Operationen.
- Windows-Installer-Build per electron-builder (CI).
- Ein vollständiger Windows-End-to-End-Lauf mit Adminlogin, Löschdialog, Coding-App-Login, Lektionen, Quiz, Start aus Launcher und Update wurde noch **nicht** durchgeführt.
- Unsignierter Windows-Installer: SmartScreen kann warnen.
- Coding-App benötigt weiterhin Internet für Supabase, CDN und externe Medien. Offlinefähigkeit nicht versprochen.
- Nur zentrale Datenbankspiele können serverseitig endgültig gelöscht werden. Github-Katalogeinträge werden archiviert, damit keine externen Repo-Dateien ohne Bestätigung beschädigt werden.
- Keine automatische Löschung von installierten Apps, lokalen Spielständen oder Daten auf anderen PCs.
- Für sehr große neue Spielpaket-Uploads fehlt derzeit noch TUS-/Multipart-Upload; das Direktupload-Limit ist weiterhin 12 MB.

## Installation
1. Neue EXE aus Github Releases v0.7.0 herunterladen.
2. Den bestehenden Launcher aktualisieren oder Installer starten.
3. Als Admin einloggen → Admin Studio → Publishing Studio → Spiele verwalten.
4. NovaLab Code unter Spiele entdecken bzw. Apps & Tools auswählen → Installieren → Öffnen.

Zur Nachprüfung: launcher/test/studio-api.test.cjs, launcher/test/download-manager.test.cjs, launcher/test/update-controller.test.cjs.
