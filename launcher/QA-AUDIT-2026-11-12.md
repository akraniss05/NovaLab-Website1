# NovaLab Studios Launcher – QA audit (12 November 2026)

Scope: mobile/desktop UI, native Windows Rust/Tauri launcher, GitHub Release update workflow, Supabase Launcher/Studio endpoints. No absolute guarantee of zero defects.

## Bugs addressed

| Area | Failure | Fix |
| --- | --- | --- |
| Downloads | Legitimate HTTPS redirects failed | HTTPS-only redirect support with hop limits |
| Downloads | Oversized or truncated streams | Download cap, length check and error cleanup |
| Windows installation | Concurrent installs of one game | Per-game lock and Tauri single-instance guard |
| Windows uninstall | Could race a simultaneous game update | Shared per-game lock |
| Windows game update | Interrupted activation could block retry | Activation staging cleanup and backup manifest recovery |
| Storage | Old game releases accumulated | Keep active and one previous version |
| Native games | HTML builds could not launch | Start HTML entrypoint in system browser |
| ZIP archives | Invalid filename, missing entry, malformed semver | Strict version, extraction and ZIP integrity tests |
| Local storage | Stale native install state and broken browser data | Disk reconciliation and normalization |
| Download UI | Interrupted transfer appeared active | Explicit interrupted status |
| Catalog | Legacy route could expose admin-archived games | Suppress hidden IDs on client and server |
| Catalog | Published genre/status were overwritten | Preserve server metadata |
| UI | Dynamic genre HTML injection | Escape labels, XSS regression test |
| Staff API | No abuse throttling for Studio POST requests | Authenticated per-account limits |
| Media | Native CSP blocked HTTPS game trailer videos | Scoped media policy |
| CI | Release digest failures, rate limits, malformed workflow and stale version tags | Authenticated API, immutable tags and test fixes |
| CI | Same temporary filename in passive old/new release test | Distinct SHA-256 verified installers |
| Packaging | Rust/Tauri and npm versions out of sync | Align version, pin Tauri CLI |

## Test coverage

- Browser Chromium: phone (390px), desktop (1440px); app navigation, search, mocked login/registration/team management, Studio editing, install/uninstall and launcher update UI.
- Corrupt localStorage, interrupted transfers, stale native game list, injected HTML in title/genre and horizontal overflow.
- Live backend without authentication: verify nine privileged API routes reject anonymous calls with 403. Public catalog release schema and HTTPS/sha256.
- Rust: valid and corrupt ZIPs, traversal, absent entrypoint, malformed semver, HTTPS-only redirects.
- Windows GitHub runner: native Rust compile, NSIS packaging and in-place old-to-new version installation. Follow the current Actions run for latest status.
- Separate passive installer test uses verified published release assets and NSIS /P /UPDATE /R.

## Still open or not conclusively verified

1. Real owner credentials and role transfer: no real-account positive-login tests were performed; mocks cannot prove actual credentials work.
2. Physical Windows PC behavior, Windows Defender / SmartScreen, hardware-specific startup and accessibility were not exercised.
3. Power failure during activation, network partitions, disk-full errors and large real game archives need additional physical tests.
4. Publisher trust: SHA-256 matches the release metadata; this does not certify software safety. Game EXEs need review and official release signing.
5. Signed official Tauri updater not configured; current update scheme is verified installer + NSIS handoff, with Windows security warnings possible.
6. Friends, chats and cloud functionality remain partly mock or demo UI and need real backend implementation.
7. Older game version is preserved as a fallback, but one-click rollback is not implemented.

## Release guidance

Do not overwrite an already published version tag. Release a new version and verify both Windows installation and passive in-app update. Only claim fully tested when corresponding GitHub Actions and release smoke tests succeed.
